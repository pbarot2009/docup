Assume we are working with this custom struct:

tinoc 
type Buffer struct {
    len usize,
    capacity usize,
}

Read-Only (Default / None)

The caller retains full ownership. The function gets a read-only view and cannot modify the variable.

Syntax Exmaple:

tinoc 
// Function Definition (no keyword before 'buf')
fn print_info(buf Buffer) void {
    let size = buf.len;
}

fn main() void {
    let my_buf = Buffer.new();
    
    // Call Site: passed normally
    print_info(my_buf);
}

Transplied C:

c 
// Emits const + restrict pointer so GCC/Clang can aggressively optimize
void print_info(const Buffer* restrict buf) {
    uintptr_t size = buf->len;
}

int main() {
    Buffer my_buf = Buffer_new();
    
    // Automatically passes address as const pointer
    print_info(&my_buf);
    return 0;
}

Compiler Guarantee: Modifying buf inside print_info triggers a compile error before C code is ever generated.

In-Place Mutation (mut)

The function receives exclusive mutable access to an existing variable in the caller's scope.

Syntax Example:

tinoc 
// Function Definition
fn clear(mut buf Buffer) void {
    buf.len = 0;
}

fn main() void {
    var my_buf = Buffer.new();
    
    // Call Site: 'mut' keyword is required
    clear(mut my_buf);
}

Transplied C:

c 
// Emits mutable restrict pointer (guarantees no pointer aliasing)
void clear(Buffer* restrict buf) {
    buf->len = 0;
}

int main() {
    Buffer my_buf = Buffer_new();
    
    // Automatically takes address for 'mut'
    clear(&my_buf);
    return 0;
}

Compiler Guarantee: The call site must pass a var binding. Passing a let variable to mut is a compile error.

Ownership Move / Consume (move)

The caller surrenders ownership of the variable to the function. The function takes responsibility for destroying the resource when it exits.

Syntax Exmaple:

// Function Definition
fn consume_buffer(move buf Buffer) void {
    // Uses 'buf'...
} // 'buf' goes out of scope here; compiler automatically calls its destructor!

fn main() {
    var my_buf = Buffer.new();
    
    // Call Site: 'move' keyword is required
    consume_buffer(move my_buf);
    
    // COMPILE ERROR: Cannot use 'my_buf' here, it was moved!
}

Transplied C:

c 
void consume_buffer(Buffer buf) {
    // ... work with buf ...
    
    // Compiler automatically emits destructor at scope end
    Buffer_destroy(&buf); 
}

int main() {
    Buffer my_buf = Buffer_new();
    
    // Value is moved to the function
    consume_buffer(my_buf);
    
    // 'my_buf' is marked dead in compiler AST; no cleanup needed here in main
    return 0;
}

Compiler Guarantee: After move my_buf, the variable my_buf is marked as invalidated in the compiler AST. Any subsequent access to my_buf causes a compile-time error.

Initialize / Out (set)

The function receives uninitialized memory provided by the caller and must populate it before returning.

Syntax Example:

tinoc 
// Function Definition
fn init_default(set buf Buffer, cap usize) void {
    buf.len = 0;
    buf.capacity = cap;
}

fn main() void {
    // Uninitialized allocation slot
    var my_buf Buffer = uninit;
    
    // Call Site: 'set' keyword is required
    init_default(set my_buf, 1024);
    
    // 'my_buf' is now safely initialized and ready to use!
}

Transplied C:

c 
void init_default(Buffer* restrict buf, uintptr_t cap) {
    buf->len = 0;
    buf->capacity = cap;
}

int main() {
    Buffer my_buf; // Stack space allocated, uninitialized
    
    // Function writes directly into caller's memory
    init_default(&my_buf, 1024);
    return 0;
}

Compiler Guarantee: The compiler verifies that every field in buf is assigned inside init_default. Returning without initializing buf triggers a compile error.

Side-by-Side Summary

Mode Parameter Def Call Site Transpiled C Param Compiler Safety Guard
Read-Only buf Buffer func(my_buf) const Buffer* restrict Read-only enforcement
Mutation mut buf Buffer func(mut my_buf) Buffer* restrict Requires var, non-null
Move move buf Buffer func(move my_buf) Buffer (or owned pointer) Caller variable invalidated
Initialize set buf Buffer func(set my_buf) Buffer* restrict Must write before return

Complete Example

Here is how all 4 modes look working together in a single pipeline:

tinoc 
fn main() void {
    // 1. Allocate uninitialized memory slot
    var buf Buffer = uninit;
    
    // 2. Initialize it ('set')
    init_default(set buf, 512);

    // 3. Mutate it ('mut')
    clear(mut buf);

    // 4. Read it (Default)
    print_info(buf);

    // 5. Move ownership ('move')
    consume_buffer(move buf);
}

Transpiled C:

c 
int main() {
    Buffer buf; // Uninitialized
    
    init_default(&buf, 512);
    clear(&buf);
    print_info(&buf);
    consume_buffer(buf); // Ownership transferred
    
    return 0;
}
